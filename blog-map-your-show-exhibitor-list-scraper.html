How to Scrape Map Your Show Exhibitor Lists?

Map Your Show Exhibitor List Scraper is a powerful web scraping tool that runs on the Apify platform* - a solution designed to automatically collect lists of companies participating in trade fairs. It is very easy to use even for non-technical users.

*Apify is a cloud platform and marketplace for web scraping and automation tools.

In this blog post, I will explain what this scraping tool does, how it works, which data fields it extracts, and which events are supported.

What Does Map Your Show Exhibitor Scraper Do?

Map Your Show Exhibitor List Scraper automatically crawls the listing and detail pages on the trade show website to generate structured data. It eliminates the need for manual data collection and provides a repeatable, scalable scraping process.

It typically automates the following steps:

  1. Crawls the exhibitor listing pages and detects all exhibitor profile links.
  2. Visits each exhibitor profile and extracts company details.
  3. Scrapes data fields such as company name, contact information, website, product categories, and social media links.
  4. Returns a structured dataset ready to download in multiple formats.

Depending on the event website, the dataset may include:

  • Exhibitor Profile URL
  • Company Name
  • Full Address
  • Phone Number
  • Website URL
  • Hall / Stands
  • Hall / Stands Sizes
  • Social Media Links (LinkedIn, Facebook, Instagram, Twitter)
  • Brands
  • Product Categories
  • Contact Persons (Name, Email, Phone, Title, Social Media Links)

Whether the event has 500 exhibitors or 5,000, the extraction process works the same way - automatically and at scale.

All data can be exported as Excel, CSV or JSON.

Supports Map Your Show Template-Based Event Websites

Map Your Show events mostly use the same website template and URL structure. Map Your Show Exhibitor List Scraper works for all event websites built on the Map Your Show platform such as:

  • The NAMM Show – namm26.mapyourshow.com/8_0/
  • integrated systems europe – ise2026.mapyourshow.com/8_0/
  • Global Health Conference & Exhibition – himss26.mapyourshow.com/8_0/

Some events may have special domains such as:

  • CES Tech – exhibitors.ces.tech/8_0/
  • CONEXPO-CON/AGG – directory.conexpoconagg.com/8_0/
  • International Manufacturing Technology Show – directory.imts.com/8_0/

If a Map Your Show event URL contains /8_0/ part, then it is supported by this scraper.

How to Scrape Map Your Show Exhibitor List?

  1. Copy the exhibitor directory URL
  2. Open the Apify actor
  3. Paste the URL in the Actor input
  4. Click Run and wait for the scraping process
